# KarenBot v2.0.0-alpha.1

在 `v2.0.0-alpha` 基础上加入**后端与当前前端分开更新**。默认行为不变：不选择组件时仍同时更新后端和前端。

## 更新内容

- 更新页每个发行版提供三个操作：
  - 重新安装/更新全部
  - 仅更新后端
  - 仅更新当前前端（GUI 或 WebUI）
- 只更新 WebUI 前端后刷新页面即可，不需要重启后端；只更新后端时才要求重启。
- 允许对当前版本重新应用所选组件，用于修复本地文件或刷新同一版本的构建。
- 后端只下载、校验并写入所选组件；未选组件保持原版本。
- 确认框和结果会明确列出本次更新的组件，并提示混用版本的风险。
- 修正更新概览中「不能只更新其中一个组件」的旧文案。

## 资产

- `modules.json`
- `KarenBot-backend-v2.0.0-alpha.1.tar.gz`
- `KarenBot-GUI-v2.0.0-alpha.1.tar.gz`
- `KarenBot-WebUI-v2.0.0-alpha.1.tar.gz`

安装器应先读取 `modules.json`，再按所选前端下载后端 + 对应前端，并用 manifest 中的 SHA256 校验。

## 升级

- **v2.0.0-alpha 用户**：这是 Pre-release，不会自动提示；请在「设置 → 更新 → KarenBot 发行版」中手动选择本版本。
- **0.1.x 用户**：先安装过渡版（后端 `v0.1.11-alpha.1`、GUI/WebUI `v0.1.1-alpha.2`），再选择本版本。
- **新用户**：使用更新后的安装器从本 Release 安装。

只更新一个组件后，两端版本可能不一致；如出现接口错误，请再更新另一个组件或重新安装全部。用户数据、人格、插件与配置不会被覆盖，更新前会逐文件备份到 `data/module_backups/`。
