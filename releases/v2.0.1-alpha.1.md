# KarenBot v2.0.1-alpha.1

`v2.0.1-alpha` 的补丁版：修复“所有渠道都停用后 Runtime 拒绝启动”的问题。

## 修复

- 当一个启用的 adapter 都没有（或配置中完全没有 adapter）时，Runtime 不再抛出
  `配置中的所有 adapter 都处于 disabled 状态`，而是进入**无渠道模式**：
  - GUI/WebUI 正常打开，模型、人格、记忆和本地功能可用；
  - 不会收发 QQ/Telegram 消息；
  - 之后在设置里重新启用渠道会自动热恢复。
- 无渠道模式下主动思考循环会跳过，避免没有发送目标时白跑模型。
- 限流回调、pipeline 默认黑白名单和 adapter 启动路径都补了空渠道 guard。

> 这个修复只解决“渠道停用导致启动失败”。模型 API Key 错误/不可达是独立问题：
> Runtime 仍会启动，但实际聊天请求会失败（例如 DeepSeek 返回 401）。

## 组件

- 后端：包含上述修复。
- GUI / WebUI：仅同步版本号，代码与 `v2.0.1-alpha` 一致。

## 升级

- 这是 Pre-release，不会自动提示；请在「设置 → 更新 → KarenBot 发行版」中手动选择。
- 用户数据、人格、插件与配置不会被覆盖；更新前会逐文件备份到 `data/module_backups/`。
- 安装器 v1.1.4 会按最新 Release 自动解析到本版本；无需单独更新安装器。
