# KarenBot v2.1.3-alpha

此版本作为 **Latest 普通 Release（非预发布）** 发布，后端、GUI、WebUI 统一为 `2.1.3-alpha`。

## 可选备份与一键恢复

- GUI 和 WebUI 的「设置 → 备份」支持分别选择配置、凭据、聊天记录、RAG、工作区、表情包、Provider 预设和人格。
- 创建前显示每类源数据大小和选中内容合计；工作区可单独选择是否包含入站媒体，大小随选择更新。任务显示分类处理进度，已有归档可查看分类大小。
- 选择备份后可勾选要恢复的类别，预览归档大小、当前数据大小及覆盖/新增文件数量；核对并输入确认短语“恢复备份”后即可执行。
- 恢复先校验归档、暂停 Runtime 并创建当前数据的回滚备份，再覆盖或新增所选文件。归档没有收录的现有文件会保留；写入或重新启动失败会尝试自动回滚。
- 恢复拒绝不安全路径、伪造类别和符号链接目标；凭据须包含可验证的密钥材料。备份 ZIP 未加密，请像密码一样保管。
- 带迁移/删除账本的聊天或 RAG 数据须通过维护控制器恢复，在线覆盖会拒绝这些类别。

## 设置与引导修复

- 修复设置保存失败后显示值、未保存草稿、并发保存和密钥引用可能与实际状态不一致的问题。
- 首次配置可先选择“暂不连接渠道”，补齐验证失败后的重试与摘要返回编辑；重新提交向导保留备份目录、局域网等已有设置。
- 统一渠道配置验证，修复白名单和模型参数默认值处理；保存及重启按钮失败后可继续操作。
- 更新主仓库中英文 README、组件 README 和安装器 README，补充备份/恢复流程及 `v2.1.3-alpha` 安装入口。
