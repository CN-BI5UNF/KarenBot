# KarenBot v2.0.0-alpha

发布日期：2026-11-21

后端、GUI、WebUI 统一为 `v2.0.0-alpha`。这是 KarenBot 首个统一发行版，安装/更新入口改为
`CN-BI5UNF/KarenBot` 主仓库。

## 发布资产

- `modules.json`：发行版清单与各资产 SHA256
- `KarenBot-backend-v2.0.0-alpha.tar.gz`
- `KarenBot-GUI-v2.0.0-alpha.tar.gz`
- `KarenBot-WebUI-v2.0.0-alpha.tar.gz`

不提供完整应用包；安装器按 manifest 组合后端 + 用户选择的前端。资产格式见
`docs/distribution.md`。

## 如何升级

- **0.1.x 用户**：先安装过渡补丁（后端 `v0.1.11-alpha.1`，GUI/WebUI `v0.1.1-alpha.2`），
  再在更新页手动选择本版本。v2 是 Pre-release，不会自动提示。
- **新用户**：使用更新后的安装器，从本 Release 安装。
- **旧 1.0.x 用户**：该绑定版本已放弃支持；请备份数据后按新安装流程迁移。

## 主要变化

- 三个组件仓库以 submodule 形式并入主仓库，版本由 `modules.lock.json` 固定。
- KarenBot Release 成为唯一发布入口；组件仓库 v2 Release 只用于源码回溯。
- 更新器读取 `modules.json`，校验 SHA256 后同时更新后端与当前前端，禁止半套更新。
- 旧的 1.0.x 发行版原样保留，并已复制归档到私有 `Debata-Refactor`。
- 包含 0.1.x 过渡版的适配器协议重构、外部程序托管和 GUI 启动稳定性修复。

## 已知限制

- 这是 alpha，接口/数据迁移仍可能变化；升级前请备份数据。
- 组件仓库不能单独升级；请始终使用本 Release。
