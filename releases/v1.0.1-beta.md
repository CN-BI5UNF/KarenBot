# KarenBot 1.0.1-beta

发布日期：2026-11-04  
版本号：`1.0.1-beta`；tag：`v1.0.1-beta`

这是 `1.0.0-beta` 之后的修复与体验版本，包含工具路由、容器文件管理、群聊触发和模型思考参数等更新。

## 修复

- 自定义 OpenAI-compatible provider 现在可以在「模型管理 → 提供商」设置「思考强度传递」风格；对支持 `reasoning_effort` 的本机 Gemini 反代选择 `openai` 后，聊天配置的 `high` 会实际随请求发送，不再只是保存在本地。
- 社交决策在上下文为空时补一条中性 user 消息，修复 Gemini 兼容端点返回 `400 contents is not specified` 的问题。
- 修复 Windows CI 中测试 fixture 创建控制字符文件名导致的 5 个 setup error；控制字符过滤逻辑改用跨平台单测覆盖。
- 人格进食/睡眠/工作等动作改为到点独立结算，并在入站与回合结束时兜底，避免后台维护间隔较长时一直停留在旧状态。

## 新增与改进

- 工具双层路由（实验）：`behavior.tool_schema_profile="routed"` 使用 `list_toolsets` / `load_toolset` 按需加载工具集，第二层用 `tool_search detail=full` 查询高级参数。
- 工具提示优化：统一 WebUI 悬停提示层；精简并补全工具描述、风险等级、工具集边界和常用工具示例。
- 群聊触发：按群设置 @ 触发窗口，支持消息数/时间上限；LLM 可通过 `group_trigger_window` 临时放行、延长或关闭窗口，最多同时覆盖 2 个群。
- 容器页文件管理合并为「本机工作区」和「容器工作区」两个模式，移除「容器根目录」入口；容器 API 只接受 `/workspace` 及其子路径。
- 文件管理支持 PNG/JPEG/GIF/WebP/BMP 图片预览，增加 15 秒前端目录缓存和容器文件读取快速路径。
- 容器配置发生变化时继续使用现有容器并提示，不再自动重建；显式重建仍保留 `/workspace`。

## 兼容性

- 配置版本与数据契约版本保持不变，现有实例无需额外的数据结构迁移。
- 从旧版本升级后如修改了 provider 设置，需要在「重启 Runtime」或「重启后端」后生效。

## 验证

- Ubuntu 3.11 / 3.12 与 Windows 3.11 / 3.12 的 CI 测试目标。
- Linux 本地全量测试与 `ruff`、`bun build`、`git diff --check` 验证。
