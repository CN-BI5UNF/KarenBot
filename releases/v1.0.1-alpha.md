# KarenBot 1.0.1-alpha

发布日期：2026-11-06

版本号：`1.0.1-alpha`；tag：`v1.0.1-alpha`

这是当前开发快照的发布版本，包含原生编码 Agent 模式、媒体失效恢复、人格状态更新加固，以及容器页和更新页的加载优化。

## 新增

- 容器页提供 Pi / DSH / Claude Code 三种编码 Agent 模式。它们只向 KarenBot 的 LLM 提供原生工具语义，不启动任何第三方 TUI / GUI / WebUI；可安装多个，但同一时间只能激活一个。
- 新增 `coding` 工具集：读取、写入、精确编辑、unified diff 补丁、命令、glob、grep、目录、待办、计划、子 Agent、Jupyter notebook 编辑。
- Pi / DSH 支持 `agent_tool_create/list/run/delete` 自定义 Python 工具；工具保存在容器 `/workspace/.karen-agents/tools`，通过 stdin JSON、stdout、退出码调用。
- 新增 `behavior.tool_schema_profile="agent"`：Claude Code 式核心工具常加载，其余工具用 `tool_search select=[...]` 延迟加载，加载状态按会话隔离。
- 本机 Claude Code 命令执行支持 bubblewrap 沙箱（默认联网）或用户显式选择的 host 整机模式。
- 人格后台新增管理员「唤醒」；群聊 @ 触发新增每群过滤缓存与 `history_limit`。
- 内置 `personas/deepseek` 完整群聊人格随版本一同发布。

## 修复

- 存储清理删除过期图片/视频后，历史消息中的失效引用不再让整轮模型调用失败；缺失或损坏的媒体会变成明确的不可用占位文本，其它媒体正常投影。畸形 metadata 和越界路径仍严格拒绝。
- 人格状态更新 JSON 解析支持代码围栏、前置说明、尾逗号和 `reasoning_content` 兜底；解析失败时记录输出长度与 `finish_reason`，不再只有一句笼统警告。
- 工具审计修复：子 Agent 视觉入口、搜索/天气错误包装、空发送、人格状态虚报成功、群申请待处理清理、知识删除、转发失败状态等。
- `run_python` 优先使用 bubblewrap 沙箱；没有 `bwrap` 时明确标注降级，不再宣称是安全沙箱。

## 性能

- 容器页并行读取状态、存储和 Agent 模式；Agent 卡片先显示加载占位，后台状态只探测一次容器并并行读取 manifest。
- 设置 → 更新先渲染占位卡片；本地 git 查询并行，更新状态不再等待联网检查/版本列表使用的更新锁。
