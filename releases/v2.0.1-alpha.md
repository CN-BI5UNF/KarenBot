# KarenBot v2.0.1-alpha

WebUI 默认收紧到本机，新增局域网开关；更新时自动修复旧安装器的桌面快捷方式图标；工具 schema 档位收进容器 Agent 模式。

## 更新内容

### WebUI 网络与安全

- WebUI 默认只监听 `127.0.0.1`（源码运行和安装器安装行为一致）。
- 设置页新增「网络」分组，可开启/关闭“允许暴露在局域网中”，并显示当前监听地址、来源和可访问 URL。
- 修改开关后需要重启 WebUI 服务；设置页提供「立即重启 WebUI」。
- 启动时仍可用 `--host 0.0.0.0` 显式覆盖配置；非回环监听会在启动横幅打印风险提示。
- 登录 Cookie 在 HTTPS 或 `KAREN_WEBUI_SECURE_COOKIE=1` 时带 `Secure`；`/api/auth/*` 响应带 `Cache-Control: no-store`。

### 更新器

- 更新 WebUI/GUI 后扫描安装器创建的 `karenbot-*.desktop`，把旧安装器的 `Icon=applications-system` 改为 `Icon=karenbot`，并把 SVG 安装到 `~/.local/share/icons/hicolor/scalable/apps/`。
- 用户自定义的图标路径不会被覆盖；旧快捷方式会保留原启动参数。

### 工具档位

- GUI 和 WebUI 的「工具 schema 档位」从 设置 → 软件行为 移到 容器 → Agent 模式。
- 设置页不再重复展示该字段；保存后热重建工具注册表，不需要重启 Runtime。

### 安装器

- 安装器 **v1.1.4** 同步发布：生成的 `launch-webui.sh` / `.cmd` 不再写死 `--host 127.0.0.1`，让设置页的局域网开关可以生效。
- 旧安装目录里的启动脚本仍是旧参数；设置页会提示“启动参数 --host 覆盖了开关”。需要局域网访问时请重新运行安装器或手动去掉启动脚本里的 `--host 127.0.0.1`。

## 资产

安装器应先读取 `modules.json`，再按所选前端下载后端 + 对应前端，并用 manifest 中的 SHA256 校验。

## 升级

- **v2.0.0-alpha.1 用户**：这是 Pre-release，不会自动提示；请在「设置 → 更新 → KarenBot 发行版」中手动选择本版本。
- **v2.0.0-alpha / 0.1.x 用户**：按更新页提示升级；0.1.x 仍需先安装过渡版。
- **新用户**：使用安装器 v1.1.4 从本 Release 安装。
- 用户数据、人格、插件与配置不会被覆盖；更新前会逐文件备份到 `data/module_backups/`。

## 已知限制

- 旧安装器的 `launch-webui.sh` 如果显式包含 `--host 127.0.0.1`，会覆盖 `webui.allow_lan`；这是启动参数优先级的设计，不会被更新器自动改写。
- 本次不改变 HTTP `?token=` 查询参数的兼容行为；共享环境建议使用 `Authorization: Bearer`。
