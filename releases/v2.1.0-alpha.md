# KarenBot v2.1.0-alpha

v2.1.0-alpha 汇总 v2.0.1-alpha.1 之后的安全审计修复、跨平台稳定性改进和容器文件导出加固。

## 修复与加固

- 修复 Windows 读取已存在 CSRF/范围删除密钥时对 `os.fchmod` 的平台依赖。
- 修复聊天分页关闭调用方持有的 `KarenDB` 共享连接的问题。
- GUI 后端重启改由外层启动器协调，避免 launcher 嵌套、Windows 标准流竞争和渲染参数残留；页面加载失败卡片补齐生命周期方法。
- 人设目录与 ZIP 导入拒绝符号链接，限制文件数和总大小，并在落盘前校验静态 `persona_prompt.py`；导出遇到不安全内容返回 400。
- 未保存 Provider 探测固定经验证的公网 DNS 地址，禁用环境代理和重定向，降低 DNS rebinding、代理绕过和密钥外泄风险。
- 容器文件导出改为容器内 `O_NOFOLLOW` 流式读取、大小上限控制和宿主机原子落盘，消除检查与复制之间的 TOCTOU 窗口。

## 验证

- 后端 Python 3.11 / 3.12：`366 passed, 1 deselected`。
- 后端 Ruff、Python 编译检查、GUI GTK4 导入检查和 WebUI 33 个 ES Module 语法检查通过。
- 本次发布为 Pre-release，不会自动提示；请在更新页手动选择。
